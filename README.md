# HT-NexusAI Website

Website tĩnh cho HT-NexusAI, gồm:

- `index.html`: Trang chủ
- `terms.html`: Điều khoản dịch vụ
- `privacy.html`: Chính sách bảo mật
- `assets/css/style.css`: CSS
- `assets/js/main.js`: JavaScript
- `assets/images/logo.png`: Logo HT-NexusAI

Không cần npm hoặc package.

## Deploy

Có thể đưa nguyên thư mục lên Vercel, Netlify hoặc GitHub Pages.

Trước khi gửi Discord xác minh, hãy kiểm tra lại Terms of Service và Privacy Policy để bảo đảm nội dung khớp với cách bot thực tế xử lý dữ liệu.
